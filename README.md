# Enterprise Windows Server 2022 Home Lab

## Project Overview

This repository documents my Windows Server 2022 Active Directory home lab (HPE ProLiant DL380 Gen 9), built to develop hands-on experience with enterprise IT administration and systems support. The lab simulates a small business environment and is continuously expanded with new technologies and configurations.

---

## Objectives

- Build practical experience with Windows Server administration.
- Learn enterprise networking and identity management.
- Practice troubleshooting common IT infrastructure issues.
- Document projects and configurations for professional development.

---

## Technologies Used

- Windows Server 2022
- Windows 11
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy
- SMB File Sharing
- NTFS Permissions
- Remote Desktop
- Tailscale VPN
- HPE ProLiant DL380 Gen9
- RAID Storage

---

## Completed

- Installed Windows Server 2022
- Configured static IP addressing
- Installed Active Directory Domain Services (AD DS)
- Configured DNS
- Created Organizational Units (OUs)
- Created users and security groups
- Configured SMB file shares
- Configured NTFS permissions
- Joined Windows 11 client to the domain
- Created Group Policy drive mappings using Item-Level Targeting
- Configured secure remote administration with Tailscale VPN
